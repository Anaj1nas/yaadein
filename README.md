# Yaadein — A Personal Memory Companion

Yaadein (meaning "memories" in Hindi) is a simple, personalized memory-support app built for elderly people and their families. Instead of generic memory games, it uses the person's own family photos and relationships — making practice meaningful, not just mechanical.

Built for **HackBIOS 2026**.

## 💡 The Idea
Many elderly people with memory loss struggle to recall familiar faces and names. Most memory-training apps are generic and impersonal. Yaadein lets a family member add real photos and names, so the games are built around people the user actually loves and recognizes.

## ✨ Features
- **Family Photo Quiz** — "Who is this?" with gentle, encouraging feedback (never harsh "Wrong!" messages)
- **Memory Match** — a classic card-matching game to exercise short-term memory
- Simple, large-button interface designed with elderly users in mind

## 🛠️ Tech Stack
- **Python** + **Streamlit** — web app and interface
- Built entirely with free, open tools — no paid APIs

## 🚀 Running it locally
```bash
pip install streamlit
streamlit run app.py
```
